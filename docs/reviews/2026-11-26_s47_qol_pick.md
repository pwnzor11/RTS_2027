# S47 QoL pick (U-13, D-336): 15 UI/input items

Picked by the package helper from the s18 lists (qol-cnc.md "cnc#", qol-modern.md) and the s43 list (QOL-xx). Every row was checked against
`git grep` in src/Game on integ-s47 and is NOT built yet. All are front end only: no sim command, no hash or golden pin moves.
Keys are rebindable actions in `GameKeys.Infos`; the free default keys are the few left (every letter, F2-F12, Home/End/Ins/Del/PgUp/PgDn are taken).
Not picked because built already: Home/centre on selection, cycle production buildings, idle harvester/factory, map-wide type select, class selects,
place last, clock, target lines, range rings (selection), per-kind alert volume, reduce flashes, screen-shake toggle, autosave, stances, waypoints.
Skipped on purpose: Ctrl-queue at front (needs a sim command), handicap (exists), research-done alert (UpgradeComplete exists), silo-full alert
(the snapshot has no storage figure), U-12 and U-04-style items (tech-tree viewer, drill missions).
