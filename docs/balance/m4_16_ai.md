# M4-16 AI: smarter spending, finishing games, 4-player targeting (round 1)

Method as in m4_ai.md: headless `Tools ai match` / `ai matrix` on the Release build, 2-player cells 8 seeds x 2 (starts swapped) = 16
games, map size 56, 25 000 ticks. Only src/AI changed; no rules numbers, no src/Sim.
**Status: round 1.** The start-0 bias (m4-16a) was not in this worktree and swamps 16-game cells (about 15 points of noise), so deeper
tuning waits for that fix. Cells not finished are marked pending.

## 1. What changed (every constant, all `(tune)` in code)

| Change | Constant | Old | New |
|---|---|---|---|
| Finish won games (flag respond_to_attacks, tier 2+) | `TierPlanner.AheadMarginPct` | n/a | 50 (our army value >= 150 % of the enemy army seen lately) |
| | `TierPlanner.AheadMinUnits` | n/a | 8 |
| | `TierPlanner.EnemyValueMemoryTicks` | n/a | 1200 (peak enemy army value in view) |
| | `MilitaryManager.AheadStageCells` | 16 (`StageDistanceCells`) | 6 when ahead; 16 otherwise |
| | `MilitaryManager.AheadStageTimeoutTicks` | 1800 | 600 when ahead; 1800 otherwise |
| | goal choice when ahead | nearest building | production / refinery buildings first, then nearest |
| 4-player targeting | `MultiTargetReviewTicks` | 600 | 300 (3 or more starts) |
| | `CountWeight` | 1 | 3 (known-building count in the target score; weakest first) |
| | `LargeMapCells` / `LargeMapRegroupPct` | n/a | 80 / 60 (regroup at 60 % of the next wave size on large maps) |
| Tech hold | `TierPlanner.TechHoldEnabled` | n/a | **false**, off pending measurement |
| | `TierPlanner.BehindMarginPct` | n/a | 20 (enemy army value > 120 % of ours) |

Tech hold (code present, switched off): while behind, `BuildOrderManager.HoldStep` skips research, the tier-2/3 gates, the air producer
and the superweapon, and `UpgradeManager` buys no research. It could not be a difficulty.toml flag (the loader is in src/Data and rejects
unknown keys). Tier 1 (Recruit) is unchanged: all new behaviour is gated on the Respond / UseUpgrades options.

## 5. Assessment

- The tech hold rarely triggers: the AI only sees enemy units occasionally, so its estimate of the enemy army is low; it stays off.
- The remaining ladder gap is probably costs: research, tier gates, scouts, raiders and retreats cost units on a 56-cell map.
- 16 games resolve about 15 points; only commissar > elite (Authority) and regular > recruit (Directorate) moved beyond that.
