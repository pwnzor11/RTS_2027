OFFICE OF RETURN  //  SECOND RELIEF FLEET  //  TELEX 0412  //  14 MARCH 2001
TO: COMMANDER, LANDING FORCE
FROM: COMMISSIONER FOR THE RETURN
RE: THE FIRST LANDING

1. THE FLEET HAS MADE THE COAST. THE CHARTS SHOW A CLEAR BEACH ON THE EAST SHORE, INSIDE THE SHALLOWS. WE WOULD BE GRATEFUL IF YOU WOULD PUT THE COMMAND SHIP ASHORE THERE.

2. ON TOUCHING DOWN THE FLAGSHIP DEPLOYS INTO THE LANDING DEPOT. EVERYTHING ELSE IS BUILT OUTWARD FROM IT: POWER, A BILLET FOR THE MARINES, A SEAWALL EMPLACEMENT.

3. SHIPMENTS FOLLOW OVER THE WATER. NOT ALL HULLS ARE REPLACEABLE. PLEASE KEEP THE LANDING CRAFT SAFE.

4. THE LOCAL AUTHORITY HAS A COAST WATCH. IT HAS SEEN US. WE DO NOT WISH TO CALL THIS A CONQUEST. WE ASK ONLY THAT THE BEACHHEAD STAND.

5. THE FLEET WILL DO ITS BEST FOR YOU. RETURN WITH THE TIDE.

-- END OF MESSAGE --
